# Team Workflow

Адаптивная реализация приложенного макета на React, Vite и CSS.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

GitHub Actions собирает `dist` и публикует сайт на GitHub Pages при изменении `main`. В настройках репозитория Pages → Source должен быть выбран GitHub Actions.

Макет воспроизведён HTML/CSS и SVG. Шрифт Inter включён локально в сборку. Ссылки ведут к существующим блокам страницы; регистрация и видео не предоставлены в исходном макете.
